# Apex TV signed menu updates

This feed serves signed version **0.5.6** menu/player assets for the original
paired Apex TV installation. The complete open-source application and public
installer package are at https://github.com/Pajuodelis/apex-tv .

The TV verifies the pinned RSA signature, both file hashes, shell compatibility
and rollback rules before applying a menu while playback is idle. Normal
playback and updates run on the television without a companion computer.

This repository contains public assets and their signed manifest only.
Account state, passwords, private keys, Samsung certificates and device
identifiers remain local. Your own eligible F1 TV account is required.
